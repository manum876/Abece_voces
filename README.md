# Abecé — voces

Audios en español de **Abecé**, la dirección de [Азбука](https://github.com/manum876/Azbuka_v3) para aprender español desde cero.

- Repo aparte de `Azbuka_voces` a propósito: cada workflow corre por su cuenta y el índice de uno nunca borra los audios del otro. Además, cada repo tiene su propio límite de 1 GB en GitHub Pages.
- **Prueba de voces:** Actions → «Prueba de voces» → Run workflow. Las muestras quedan en `prueba/` y se escuchan en `https://manum876.github.io/Abece_voces/prueba/`.

Voces candidatas: [Silero TTS](https://github.com/snakers4/silero-models) (v3_es, licencia CC BY-NC 4.0, solo uso no comercial) y [Piper](https://github.com/rhasspy/piper) (es_ES, para comparar).
